# TFTDataAnalyzer 리뷰 가이드

## 언어
- 모든 리뷰 요약과 코멘트는 **한국어**로 작성한다.

## 프로젝트 범위
- TFT 정적 데이터와 과거 경기의 익명 집계를 분석하는 Unity(C#) 도구다. 전투 시뮬레이션과 미래 승패 예측은 범위 밖이다.
- 설계와 작업 규칙은 `AGENTS.md`, `README.md`, `Assets/Plan/TFTDataPipeline.md`를 기준으로 한다.

## 우선적으로 확인할 것
1. **데이터 보존·손상**: 기존 카탈로그와 저장 데이터를 덮어쓰거나 깨뜨리는 변경, 저장 형식·스키마 호환성 문제.
2. **비밀값·개인정보**: API 키, 토큰, 식별 가능한 원본 경기 응답이 코드, 로그, 테스트 데이터, 커밋에 들어가는지 확인한다.
3. **공통 계약**: 공통 파서·저장소·분석 계약 변경이 다른 기능에 미치는 영향과, 그에 맞는 테스트가 있는지 확인한다.
4. **오류·복구 처리**: 네트워크 실패, 부분 응답, 잘못된 데이터에 대한 예외 처리와 복구.
5. **테스트**: 변경된 기능에 대응하는 EditMode 테스트가 추가되거나 갱신되었는지 확인한다.

## 줄일 것
- 동작에 영향이 없는 순수 취향 수준의 스타일 지적은 하지 않는다.
- Unity가 자동 생성하는 파일(`*.csproj`, `*.sln`, `*.meta`의 단순 변경)에는 코멘트하지 않는다. 단, `.meta`의 GUID 변경은 참조 깨짐 위험이 있으므로 지적한다.
