# 조합 기준 변경 체크포인트

상태: 사용자가 승인한 구현과 독립 검수를 수행하고 PR 준비 중이다. 최종 사용자 승인과 CodeRabbit 검수는 아직이다.

사용자는 경기 종료 시점의 기물 목록과 활성 시너지만을 조합의 기준으로 삼고, 성급·아이템·증강을 조합 구분에서 제외한다고 결정했다. 아이템과 증강 필터를 선택하면 해당 조건에 맞는 관측만으로 통계를 재계산하기로 했다. 실제 마지막 전투의 투입 기록 대신 종료 시점 목록을 사용하기로 했다.

기획 A와 B는 동일한 비식별 고정 입력을 각각 검토했다. 구체적인 결과와 검증 조건은 [구현 계획](ImplementationPlan.md), B의 전달 내용은 [기획 B 기록](PlanningB.md), A의 자료는 `AntigravityCollab/tasks/2026-11-09-relaxed-composition/`에 있다.

사용자는 상대 비교에서 두 조합 중 한쪽만 조건을 만족해도 비교하고, 기물과 아이템을 함께 선택하면 선택한 기물이 해당 아이템을 직접 장착한 경우만 포함하기로 결정했다. 예시 설명을 들은 뒤 같은 기물을 사용한 수량이 다르면 다른 조합으로 구분하기로 했다. PR #28은 검수 완료·CodeRabbit 검사 통과·미해결 검수 대화 없음 상태에서 `39e53d834b9ea03b2920da81f7557c591492e1a8`에 병합됐다. 문서화 비율 23.53% 경고와 검증 스크립트의 비차단 오류 사유 기록 제안은 별도 사실로 남긴다. 사용자 미커밋 변경은 보존한다. 실제 경기 API 호출은 하지 않았다.

다중 범위의 부분 저장 문제를 발견해 별도의 완성된 세대 단위로 게시하며, 사용자는 같은 결과를 재사용하고 한도 도달 시 직접 정리하는 방식을 선택했다. 완성 세대와 남겨진 임시 작업은 각각 32개 상한을 적용한다. 이전 캐시·관측·카탈로그는 자동 삭제하지 않는다. 전체 EditMode 중간 확인은 총 1,151개 중 1,149 통과·실패 0·호스트 링크 제약 2개 제외였으며, 이후 캐시 재사용 구현이 변경되어 최종 전체 검증과 구분한다.

현재 제품 코드 기준 전체 EditMode는 1,158개 중 1,156 통과·실패 0·호스트가 심볼릭 링크 생성을 허용하지 않아 2개 제외다. 이후 테스트 코드만 추가해 아이템·증강 동시 필터의 참가자 단위 AND, 필터 뒤 증강 정책 재평가, 화면→CSV 조건과 표본·분자의 일치 통합 사례 1/1을 별도 확인했다. 추가 테스트는 위 전체 건수에 포함하지 않는다. 전체와 통합 테스트 전후 기존 EditorWindow 9개·ContainerWindow 1개 ID 및 포커스를 보존했다.

분석 화면은 합성 자료로 940px·500px의 상단·조합·상대비교 각 3장, 총 6장을 실제 이미지로 확인했다. 검증 창 정상 종료·기존 창 보존·소유 창 잔류 0을 확인했다. 이는 화면 배치의 증거이며 실제 경기 API 사용 검증은 아니다. 미완성 관측 파일 꼬리와 인덱스에 대한 기존 저장소 복구는 유지된다. 새 기능은 완성된 관측과 카탈로그를 수정하지 않는다.

독립 검수는 완화 조합·엄격 중복 탐지·혼합 증강 정책·상대 비교를 확인하고, 임시 캐시 변경 감지·소스 읽기 실패·상한별 안내를 보완하도록 지적했다. 보완 후 저장 테스트 23/23과 통합 화면 테스트가 통과했고 재검수에서 추가 차단 결함은 발견되지 않았다. 후보 symlink/권한 오류와 별도 인스턴스 generation 동시 실행의 새 전용 검증은 미실행이다. 참고: 최종 전체의 건너뛴 두 사례는 각각 컴플라이언스 설정과 격리 보고서의 테스트용 링크 생성 호스트 제약이다.

기획 A의 `gemini-4-argon-medium`/medium 및 19,415 토큰·100.748초는 기록된 런타임 수치다. 기획 B와 구현·코드검수·QA 역할의 실제 모델·추론·사용량은 확인되지 않았다. 일부 기존 담당자는 환경 사용량 한도에 도달해 반환하지 못했으며, root가 남은 작업과 검증을 수행했다. 사용 방법은 [조합 분석 안내](../../../../../docs/relaxed-composition.md)다.
