비차단 P3는 Idle 기본 안내가 카탈로그 선택을 다시 요청하는 문구다. 활성 identity·시작 가능 여부·승인·수집 동작에는 영향이 없으며 후속 문구 개선으로 남긴다.

실제 Riot 네트워크·실제 자격 증명·네이티브 확인창 클릭은 미실행이다. 현재 통제된 실패 정리 결과가 OS crash·연결 끊김·모든 timeout을 입증하지 않는다. 과거500px의 다른 화면 캡처 원인 해결을 주장하지 않고 앞으로도 실제 PNG를 검사한다. Console 전체 오류0으로 보고하지 않는다.

코드/실행 QA 통과와 사용자 최종 승인·커밋·PR/CodeRabbit 검수·병합은 별도 단계다. Task4–6와 Hermes 일일 자동화는 이번에 구현하지 않았다. 요청 모델은 GPT-6.1 Sol/High이며 실제 runtime 모델·추론·사용량은 독립 확인 불가다.
