# 정책 안내와 배포 빌드 차단 사용법

작성일: 2026-10-19. 상태: 구현·독립 코드 검수·실행 검증·별도 QA 통과. PR 검수와 사용자 최종 승인은 별도다.

`TFT Analyzer > Open Data Analyzer`의 **정책 안내** 탭에서 데이터 출처, 공식 정책 링크, 두 비공식/IP 고지, 익명화·지표 정의·제외 기능을 확인한다. 작은 창에서는 내용을 스크롤한다. 탭을 열거나 정책 링크를 열어도 정책 확인 시각이 저장되지 않는다.

등록 확인 기록은 `Project Settings > TFT Data Analyzer > Compliance`에서 편집한다.

1. 검토한 날짜를 `yyyy-MM-dd`로 입력한다. 미래 날짜는 허용하지 않는다.
2. 미확인은 `Unverified`, Portal에서 Approved 또는 Acknowledged 상태를 직접 확인했다면 `ApprovedOrAcknowledged`, 철회는 `Withdrawn`을 선택한다.
3. 최초 등록 확인은 직접 확인 체크 후 **확인 기록 저장**을 누른다. 저장 성공 여부와 저장된 상태를 확인한다. 저장 실패 시 기존 기록과 입력 초안을 보존한다.

설정은 Git 제외 `Library/TftAnalyzerStore/compliance.json`에만 기록한다. API 키나 seed를 입력하지 않는다. 기록은 사용자의 확인 메모이며 Riot의 온라인 승인 검증이 아니다. 정책 안내 탭에 다시 들어가면 최신 저장 상태를 읽는다.

유효한 필수 메타데이터와 등록 확인 기록이 없거나 설정이 손상·접근 불가·철회 상태면 **이 프로젝트의 Player 빌드**를 `BuildFailedException`으로 차단한다. 빌드 직전에 파일을 다시 읽는다. Editor 데이터 탐색과 기존 개인 연구용 로컬 집계 CSV에는 이 등록 조건을 적용하지 않는다. 공개 게시·공개 내보내기 기능은 추가하지 않았다.

검증은 전체 EditMode 546건 중 **545통과·0실패·1건너뜀**이다. 파일 심볼릭 링크 생성은 호스트 권한으로 건너뛰었고, 디렉터리 접합점 거부는 실제 실행했다. 실제 Player 빌드, Riot 온라인 승인 조회, 외부 데이터 갱신 중단, 취소·연결 끊김 실증, Task 6 버전 예약은 이번 검증 범위 밖이다. 정책 고지와 원문 출처는 [승인 계획](ImplementationPlan.md)에 연결돼 있다.

정상·표시 전 예외·표시 후 예외에서 기존 창 9개와 native 프레임 1개를 보존하고 소유 잔류 0을 확인했다. 실제 PNG 6장을 root와 별도 QA가 직접 확인했다. 상세 실행 근거는 [개발 보고](DevelopmentReport.md), [QA 보고](QAReport.md)를 따른다.
