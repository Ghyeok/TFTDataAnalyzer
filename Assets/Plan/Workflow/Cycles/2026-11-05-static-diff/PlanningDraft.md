# 정적 비교 화면 원문 표시 계획 초안

상태: 기획 A revise와 독립 기획 B 의견을 통합한 표시 수정·독립 QA 완료, PR 전. 활성 목표 2번과 사용자의 정적 기능 개발 지속 요청 범위다.

## 목표와 범위

패치 비교에 나오는 이전·이후 값과 ID를 서식으로 해석하지 않고 원문으로 표시한다. 서로 다른 카탈로그의 선택·방향·변경 계산, 기존 카탈로그 파일과 원본 텍스트는 보존한다. 기물·시너지·아이템·증강 검색과 비교 계산을 새로 만들지 않으며 실제 API를 호출하지 않는다.

## 근거와 기술 검토

- 수정 전 `CatalogDiffer`의 필드명·이전/이후 값과 외부 안정 ID가 `DataManagerTab.RenderDiff/AddEntityDiff`의 Label 및 Foldout 제목에 전달될 때 리치 텍스트를 명시적으로 끄지 않았다. Unity 합성 Label의 기본 `enableRichText`는 true다. 수정 후 창작 데이터의 940/500px 실제 비교 PNG를 확인했다. 수정 전 실제 비교 PNG는 찍지 않았으며, 기존 확인되지 않은 렌더링을 새로운 실패 증거로 만들지 않는다.
- B는 이전/이후 카탈로그 식별 문자열, 추가·삭제 ID, 변경 레코드 제목, 필드명 및 값과 Foldout 내부 Toggle/Label을 포함한 비교 트리에만 서식 해석 차단을 권고했다. 새 비교로 다시 생성되는 요소도 처리하고 태그를 삭제하거나 이스케이프한 문자열로 대체하지 않는다.
- 관계 ID·효과·출처의 내부 구분자는 임의 원문 안에도 존재할 수 있어 단순 분할·치환으로 원래 목록 경계를 복구하지 않는다. 그 가독성과 서로 다른 효과 사전의 문자열 충돌은 별도 정확성 문제로 기록하고 실제 코드로 회귀 재현 후 별도 설계한다.

후속 실제 코드 재현: 검증 오류가 없는 합성 카탈로그 쌍을 Unity의 현재 비교기에 넣었을 때 서로 다른 효과 사전이 동일한 문자열로 합쳐져 변경 기물이 0개였다. 이는 실제 사용자 카탈로그에서 발생했다는 뜻은 아니다. 합성 probe는 `Library/TftAnalyzerValidation/StaticDiffCollisionProbe.cs`에 있으며 API·제품 파일은 변경하지 않았다. UI 표시 문제와 비교 계산 문제를 각각 검증해야 한다.

추가 실제 코드 재현: `Library/TftAnalyzerValidation/StaticDiffExtendedProbe.cs`에서 서로 다른 시너지 연결 목록과 서로 다른 출처에 대해서도 검증 오류 0·변경 기물 0을 확인했다. 효과·연결·출처 모두 구조를 보존하는 표현으로 비교해야 할 근거다. 해당 문제를 단순 화면 제어문자 치환으로 해결했다고 판단하지 않는다.

## 검증·완료 조건

1. 투명 색상·굵기 태그가 들어간 합성 전후 값, 변경 ID 및 Foldout 제목을 포함해 RED를 확인하고 표시 요소의 rich text를 차단한다. `Label.text`만 확인하지 않고 실제 렌더링 요소의 설정을 검증한다.
2. 정상 값, 네 종류, 전후 방향 전환, 반복 비교에서 원본 문자열·계산 결과·기존 카탈로그가 보존되는지 시험한다. 구분자 포함 원문을 단순 치환하지 않는다.
3. 940/500px 화면을 합성 자료로 캡처해 태그 원문과 전후 값의 가독성을 직접 확인한다. 소유 창의 성공/예외 정리와 기존 창·native frame·포커스 보존을 확인한다.
4. 독립 코드검수·QA·관련 회귀를 마치고 문서와 PR을 정리한다. 실제 데이터나 API 호출 없이 확인한 범위만 주장한다.

동일 입력은 `AntigravityCollab/tasks/2026-11-05-static-diff-planning/inputs/`에 있다. 사용자의 Antigravity 자동 진행 지시 후 A(Gemini 4 Argon Medium)는 실행 성공, revise를 반환했다. Foldout 내부 Toggle/Label의 rich text 비활성화와 원문 보존을 함께 단언하고, 여러 필드·긴 텍스트를 940/500px의 줄바꿈·스크롤·클리핑과 창 정리로 확인하며, 계산 충돌은 별도 범위로 분리하라는 요구를 위 조건에 통합했다. A의 통합안 재검토는 실행하지 않았다.
