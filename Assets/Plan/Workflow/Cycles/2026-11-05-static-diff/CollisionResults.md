# 정적 카탈로그 구조 비교: 검증 기록

상태: 구현 및 독립 검수 진행, PR 작성 전. 이 변경은 PR #26의 비교 표시 개선을 선행 조건으로 한다.

기존 비교는 관계 ID·효과·출처를 구분자 하나로 이어 붙여 서로 다른 구조를 같은 값으로 판단할 수 있었다. 이제 각 원소를 구조적으로 비교한다. 기존 공개 Before/After 문자열은 유지하고, 화면에는 비교 당시의 두 카탈로그에서 가져온 구조를 구별 가능한 형식으로 표시한다. 긴 값은 페이지로 살펴볼 수 있다. 이 충돌은 합성 자료로 확인했으며 실제 사용자 카탈로그에서 발생한 증거는 없다.

## 검증

- 합성 충돌 회귀 테스트는 수정 전 실패를 확인했고, 수정 후 관련 비교기 테스트 65건과 UI 테스트 15건이 통과했다.
- 전체 Unity EditMode 테스트는 1089건 중 1087건 통과, 0건 실패, 2건 건너뛰기였다. 건너뛴 검증을 통과로 취급하지 않는다.
- 효과·관계·출처와 긴 값의 처음·끝을 940px 및 500px 합성 화면 10장으로 확인했다. 기존 비교 화면도 두 너비에서 다시 확인했다. 정상과 표시 전/후 예외 검증에서 기존 창·프레임·포커스가 보존되고 검증 소유 창이 남지 않았다. 연결 끊김이나 모든 시간 초과 사례를 실증한 것은 아니다.
- 실제 로컬 18.2 카탈로그를 메모리에서 복제본과 비교했을 때 제품 serializer 결과와 파일 바이트가 바뀌지 않았다. 비교 전후 SHA256은 `B306B524FAD37119EA88FE28F2F7241423EE997F06BDDC563890ADB35F0C27F9`이다. 합성 충돌에 대해서는 정방향·역방향·반복 비교 전후 직렬화 불변을 테스트했다.
- 독립 코드 검수와 QA에서 제품 코드·회귀 테스트·화면 검증 도구의 수정 필요 결함은 발견하지 못했다. QA는 전체 테스트의 원시 결과 파일을 별도로 대조하지 못해 실행 담당자의 결과를 사용했다.
- 실제 Riot API 호출이나 경기 원문 수집은 수행하지 않았다. 실제 데이터에서의 저장 성공을 보장하는 변경이 아니다.

## 기획과 이력

기획 A는 Antigravity Gemini 4 Argon Medium으로 동결 입력을 검토했다. 기획 B는 GPT가 검토했고 실제 모델·추론 설정을 별도로 확인하지 못했다. 검토 요청·응답은 프로젝트의 `AntigravityCollab/tasks/2026-11-06-static-diff-collision/`에 있다. 강제 도구 차단과 A의 통합안 재검토는 실행하지 않았다.
