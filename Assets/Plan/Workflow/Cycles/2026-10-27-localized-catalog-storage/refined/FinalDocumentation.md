# 현지화 문자열 분리 저장 사용 안내

상태: 진행 중

새로 가져오는 카탈로그는 형식 5로 이름과 설명의 한국어·영어 문자열을 별도 표에 저장한다. 기존 화면은 저장된 문자열을 불러와 이전처럼 표시하며 한국어가 없고 영어가 있는 경우 영어 대체 여부를 유지한다. 사용자가 별도 설정을 바꿀 필요는 없다.

기존 형식 1~4 카탈로그는 자동으로 변환하거나 덮어쓰지 않는다. 동일한 기존 데이터는 기존 형식과 해시를 보존한다. 별도 표의 키·종류·값·출처가 잘못된 형식 5는 거절한다. 원본에 없는 번역을 만들지 않으며 실제 경기 수집이나 증강 통계 허용은 추가하지 않았다.

Unity 최종 테스트는 999건 중 997통과·실패0·환경 제한 2건 제외다. 독립 코드검수와 QA를 통과했다. 버전 확인 상태 파일 1개 변경 및 Unity 도구 통신 오류 2건의 원인은 미확정이며 [QA 기록](QAReport.md)에 남겼다. 실제 경기 데이터 검증과 사용자 최종 승인은 별도로 남아 있다.
