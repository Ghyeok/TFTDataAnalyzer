# 정적 카탈로그 변경 요약 체크포인트

상태: 개발 및 독립 코드 검수·QA 확인, PR 준비 중. 최종 사용자 승인 전이며 실제 다운로드 검증은 하지 않았다. 기준 제품 트리 `8352753584913b0b99a0bc635d6b58fb2ef2c5f5`.

2026-11-09 현재 세트·출처가 같은 로컬 기준을 선택해 신규 게시된 매니페스트에 네 종류의 추가·변경·삭제 레코드 수와 양쪽 identity·해시를 기록한다. 게시 후 읽기에서 기준을 찾아 재계산하여 요약을 확인하며, 기준 부재·손상과 잘못된 요약을 구분한다. 기존 게시 파일은 재작성하지 않는다. [사용 방법](../../../../../docs/static-change-summary.md).

기획 A는 `AntigravityCollab/tasks/2026-11-07-static-change-summary/`에 기록된 동일한 입력에 대해 `revise`를 반환했다. 모델은 런타임 기록상 `gemini-4-argon-medium`, 추론 medium, 9,612 tokens, 30.045초다. 해시 포함 가능성은 미확인 가설이었고 구현 전 코드 확인 결과 요약은 콘텐츠 해시에서 제외된다. 기획 B는 같은 입력을 독립적으로 검토하고 기준 고정·검증과 기존 파일 보존을 권고했으며, 보정된 사실을 전달한 재검토에서 새 매니페스트 기록을 수용했다. B의 실제 모델·추론·사용량은 확인되지 않았다. 사용자가 해당 구현 계획을 승인했다.

독립 코드 검수의 canonical/legacy 경로, 세트 번호 검증, 기준 변경 사용자 안내 지적 3건을 반영했다. 동일 담당자의 재검수에서 추가 중대 지적은 없었다. 독립 QA는 요구사항 대비 네 종류 전체 및 가져오기 도중 기준 변경 테스트를 요청했고 추가 후 재검토에서 추가 필수 결함을 발견하지 않았다. QA 담당자는 Unity 실행·이미지 확인을 직접 하지 않았으며 아래는 주 담당자의 실행 결과다.

2026-11-09 관련 EditMode 테스트: 파이프라인 29/29, 로더 43/43, 데이터 관리 VM 28/28, writer 2/2, differ 65/65, 데이터 관리 화면 18/18, 구조화 게시 16/16, 현지화 게시 15/15, 출처 게시 7/7, 데이터 관리 서비스 1/1. 새 UI는 합성 자료로 940px·500px 4장 픽셀을 직접 확인했다. 정상 및 표시 전·후 예외 검증에서 기존 EditorWindow 9개·ContainerWindow 1개 ID와 포커스가 보존되고 소유 창 잔류가 없었다. 실제 API 호출은 0회다.

기존 writer의 추가 매개변수는 선택적이고 로더 변경은 정적 카탈로그 목록 및 저장된 요약 표시에 한정된다. 경기 수집·분석 계약과 공유 파서는 수정하지 않았으므로, 영향을 받는 게시·구형/현지화·로더·UI·비교 회귀를 실행하고 전체 EditMode는 실행하지 않았다. 별도의 `TftDataAnalyzerEndToEndTests` 실행은 명령 출력이 수집되지 않아 결과 미확인으로 둔다. 전체 테스트 통과로 해석하지 않는다.

변경 범위 밖 사용자 파일과 로컬 카탈로그는 보존한다. 화면 검증 자료는 Git 제외 `Library/TftAnalyzerValidation/catalog-window-{940,500}-summary-{baseline,result}.png`다. 제품 구현의 실제 모델·추론·사용량은 확인하지 못했다.
