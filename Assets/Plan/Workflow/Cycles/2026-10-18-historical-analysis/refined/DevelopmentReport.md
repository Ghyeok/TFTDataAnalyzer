# 과거 집계 분석 개발 결과

작성일: 2026-10-19. 상태: 구현·코드 검수·실행 검증·독립 QA·문서 대조 통과. 통합 PR 검수와 사용자 최종 승인은 별도다. 원래 Phase3 Task4 범위다.

분석 탭의 로컬 새로고침이 기존 익명 관측 저장소·AggregateBuilder·AggregateStore·MetricPolicy를 연결한다. 저장 전용 캐시에서 조합을 역추정하지 않고 같은 관측 snapshot에서 기물 성급·장착 아이템·활성 시너지·증강 설명을 만든다. UI/CSV 수치는 정책 DTO만 사용하며 실제 증강 분류를 임의로 추가하지 않는다. 복구 읽기는 저장소 전체 인덱스와 미완성 꼬리를 복구할 수 있고, 화면 열기나 필터 변경으로 실행되지 않는다.

지역·큐·티어·구성 교집합은 불변 결과를 메모리에서 좁힌다. 활성 카탈로그 전체 identity와 세트 번호를 대조하며 schema1의 검증된 공식 identity도 별도로 전달한다. 범위를 합산하지 않고, 쌍은 한 endpoint 전체가 조건을 만족해야 한다. 표는20행 단위이며 CSV는 현재 필터의 모든 페이지를 담는다. 표본·관측 경기 시각·상태·정책이 허용한 평균과 비율/분자/분모/95% Wilson 구간을 표시한다.

CSV는 프로젝트 밖의 개인 연구용 UTF-8 파일이며 허용된 DTO만 받는다. 비율이 차단되면 metric·분자·분모·추정·구간6칸이 공란이다. 수식 텍스트를 무력화하고 invariant 숫자·UTC를 사용하며 staging 후 교체한다. 경로 링크와 장치 namespace를 거부하고 Windows 파일 핸들로 실제 부모 디렉터리를 대조해 짧은 경로 별칭도 막는다. API 키·등록 상태와 별개다.

수집 및 데이터 탭의 동작을 넓히지 않고 창의 기존 검증 행을 분석에도 전달한다. 재생성은 VM을 보존하고 binding만 교체한다. 선택 변경·취소·닫기 뒤 늦은 완료는 게시하지 않는다. 저장 창 전후에는 DTO와 화면 필터 값을 함께 대조하며 지연된 UI 이벤트가 오래된 결과를 저장하지 못하도록 한다.

## 검수·비용 기록과 한계

독립 기획2건과 별도 코드 검수에서 IO 경계·full identity·정책 억제·CSV 경로·취소와 창 정리를 확인했다. 코드 검수의 Windows 별칭 지적과 실행에서 드러난 저장 modal 이벤트 순서 문제를 수정했다. 후반 수정·통합·실행은 root가 맡았다. 구현 에이전트가 사용량 제한으로 끝난 응답은 완료로 간주하지 않았다.

Sol High(다중 모듈·복구/취소), Astra High(데이터/표시·파일 보존 검수)를 요청했고 실제 runtime 모델·추론·총 토큰·총 활성 시간은 독립 확인하지 못했다. 확인 가능한 실행 시간은 전체54.24초, CSV4.32초다. 재작업은 경로 무한 루프·modal 이벤트/안내 유지·캡처 정렬/가림 처리다. 숨겨진 추론이나 비밀값은 기록하지 않았다.

실제 네트워크·사용자 API 키/seed·실데이터 분류·네이티브 대화상자 클릭은 수행하지 않았다. 파일 보존은 정상 교체와 직렬화 전 실패로 검증했고 OS 교체 오류를 주입하지는 않았다. Task5 정책/빌드 gate와 Task6 startup/전체 E2E는 남아 있다. 코드 검수는 [원문](../raw/Reviewer.md), 실행은 [증거](../raw/ValidationEvidence.md)를 따른다.
