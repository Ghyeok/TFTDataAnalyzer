# 과거 관측 결과 보기

작성일: 2026-10-19. 상태: 구현·실행 검증·독립 QA·문서 대조 완료. PR 검수와 사용자 최종 승인은 별도다.

1. `TFT Analyzer > Open Data Analyzer`의 데이터 관리 탭에서 검증된 카탈로그를 선택한다. 분석은 그 패치·원본 버전·출처를 기준으로 하며 다른 패치는 데이터 관리에서 선택한다.
2. 과거 집계 분석 탭에서 `로컬 집계 새로고침`을 누른다. 기존 익명 관측을 읽고 인덱스·미완성 끝부분을 복구할 수 있으며 집계 캐시를 다시 만든다. 경기 API를 호출하지 않고 새 관측을 수집하지 않는다. 수집 뒤 통계 반영도 이 버튼으로 명시적으로 실행한다.
3. 지역·큐·티어 기록 라벨·기물·활성 시너지·장착 아이템·증강을 고른다. 조건은 같은 조합 안에서 모두 일치해야 한다. 아이템 조건이 선택 기물에 장착됐다는 관계까지 뜻하지는 않는다. 전체는 서로 다른 지역/큐/티어 범위의 행을 나열한다. 티어는 인증된 실제 랭크가 아닌 수집 당시의 기록 라벨이다.
4. 조합의 참가자 관측 수와 평균 최종 순위, 허용된 상위4위/1위 비율·95% 구간을 읽는다. 표본100 미만은 표본 부족이며 비율을 숨긴다. 정책이 평균도 차단하면 평균을 복원하지 않는다. 검토된 증강 분류 자료가 없으면 증강 조합은 표본이 많아도 비율이 제한된다.
5. 상대 배치 우위율은 `A`가 `B`보다 최종 순위가 높았던 비율이다. 같은 로비의 최종 순위 비교이며 실제 전투 승률이 아니다. 표본은 비교 가능 로비 수이고 중복 조합으로 모호한 로비는 제외 건수로 표시한다. 구성 필터는 A 또는 B 한쪽 전체가 모든 조건을 만족해야 한다.
6. 표는20행씩 이전/다음으로 넘긴다. `필터 결과 전체를 개인 연구용 CSV로 저장`은 현재 필터의 모든 페이지를 저장한다. 프로젝트 밖의 일반 `.csv` 경로를 고른다. API 키나 등록 확인은 필요하지 않다. 취소하면 저장하지 않고, 저장 창이 열린 사이 대상/필터가 바뀌면 다시 저장하도록 안내한다.

관측 기간은 실제 경기 시각의 범위이며 가져온 시각이 아니다. 빈 범위는 관측 없음으로 표시한다. UI 재생성은 현재 필터와 결과를 유지하며 창을 닫으면 진행 작업을 취소하고 늦은 알림을 차단한다. 실제로 새로고침한 결과만 표시하며 자동 수집/자동 새로고침은 없다.

CSV의 estimate/lower/upper는0~1 분수이고, 허용된 평균·표본·scope·UTC 기간·상태를 포함한다. 차단된 비율의 metric·분자·분모·추정·구간은 모두 공란이다. 원본 관측·경기 해시를 내보내지 않으며 공개 게시 기능은 추가하지 않았다.

현재 검증은 가짜 관측/카탈로그 및 임시 로컬 저장소로 전체495/495, UI7/7, CSV5/5다. 정상 및 표시 전/후 실패에서 검증 창을 정리했고 실제940/500px 화면을 확인했다. 실제 Riot 호출·실데이터 증강 분류·네이티브 파일 대화상자 클릭·모든 timeout/연결 끊김 복구를 검증한 것은 아니다. 정책 안내·빌드 차단·시작 시 버전 확인은 후속 Task5/6이다.

Hermes CodeRabbit5분 확인 예약은 사용자 요청으로 paused다. [운영 지침](../../../../../../docs/coderabbit-monitoring.md)을 따르며 사용자 명시 재개 전에는 켜지 않는다.
