# 과거 집계 분석 연결 계약

작성일: 2026-10-18. 상태: 진행 중. 승인 범위: 기존 Phase3 Task4와 사용자 재개 요청. 원래 [구현 계획](../../../../Implementation/2026-09-17-tft-analyzer-editor-ui.md)이 유일한 TODO 원본이며 이 문서는 연결 결정을 기록한다.

독립 검토 A/B는 저장 전용 AggregateStore와 해시만 남는 조합 집계에 읽기·필터용 연결이 필요하다는 데 동의했다. 기존 범위의 연결 작업으로 처리하며 새 집계 스키마나 실데이터 증강 분류 체계를 만들지 않는다.

- 명시적 로컬 새로고침만 ObservationStore 복구 읽기, AggregateBuilder, AggregateStore 저장을 실행한다. 동일 관측 snapshot에서 구성원 ID와 정책 DTO를 만들고 한 번에 게시한다. 화면 열기·재생성·탭 전환·필터 변경은 이를 실행하지 않는다.
- 검증된 `(StaticCatalog, CatalogIdentity)`와 세트 번호를 모두 대조한다. legacy schema1은 별도로 검증된 공식 전용 identity가 필요하다. 선택이 바뀌면 이전 행·CSV 권한을 즉시 제거하고 늦은 완료를 무시한다.
- 활성 패치에 고정한 지역·큐·티어·유닛·활성 시너지·아이템·증강 교집합을 사용한다. 전체 선택은 scope별 행을 나열한다. 쌍은 적어도 한 endpoint가 모든 구성 필터를 만족해야 하며 기존 방향을 유지한다.
- 표시·CSV 수치는 MetricPresentation에서만 가져온다. 표본99는 비율 필드가 없고100부터 정책이 허용한 비율만 표시한다. 정책 차단은 표본보다 우선하며 nullable 평균을 복원하지 않는다. 분류 자료가 없는 증강은 fail-closed를 유지한다.
- 상대 배치 우위율은 같은 로비의 최종 순위 비교다. 방향·유효 로비 표본·모호한 로비 제외·분자/분모·95% Wilson 구간을 함께 설명한다.
- CSV는 개인 연구용 UTF-8 로컬 파일이며 현재 필터의 허용 DTO만 담는다. 억제된 비율의 분자·분모·추정·구간은 모두 공란이다. API 키나 등록 상태로 차단하지 않는다. 수식 해석·CSV quoting·원본 경로 덮어쓰기 방지와 실패 시 기존 파일 보존을 검증한다.

검증은 행동 RED → 최소 구현 → 관련 GREEN, 실제 임시 관측 저장소 기반 짧은 통합, 독립 코드 검수와 QA, 최종 전체 EditMode 및 소유 창 정상/예외 정리·940px/500px 직접 화면 확인으로 수행한다. 아직 실행하지 않은 검증을 통과로 기록하지 않는다. Task5 정책/빌드 gate와 Task6 scheduler/전체 E2E는 수행하지 않는다.

요청 모델·추론은 멀티모듈·취소 작업 기준 Sol High다. 실제 실행 모델·사용량은 에이전트가 확인하지 못하면 미확인으로 기록한다. 공개 가능한 독립 응답은 [A](../raw/PlanningAgentA.md), [B](../raw/PlanningAgentB.md)에 보존했다.
