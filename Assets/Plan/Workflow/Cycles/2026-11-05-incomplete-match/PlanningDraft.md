# 불완전 경기 보관·열람 기획 초안

상태: 기획 A revise·B 조건부 검토 완료, 세부 계약 통합 중. 제품 코드 미변경. 기준 main ba50db8ad5ef8dc6ef58153cee57da0f8555588c.

## 사용자 결정

읽을 수 있는 항목은 익명으로 별도 보관·열람하고 실제 빈 값과 알 수 없음을 구분한다. 확인이 필요한 기록에는 그 상태를 표시하고 사용자가 카탈로그를 참고용으로 볼 수 있게 한다. 참고 카탈로그의 패치를 실제 경기 패치로 단정하지 않는다. 복구할 근거가 없으면 알 수 없는 상태를 유지한다.

## 기획 B 권고와 제한

- 정상 관측과 별개의 전용 모델·저장 경로를 사용하고, 일반 경기 저장소·인덱스·집계·CSV와 구조적으로 분리한다. 첫 구현의 자동 승격·수동 덮어쓰기·기존 카탈로그 수정을 제외한다.
- 값과 상태를 구분한다: 확인된 값, 명시적 빈 배열, 누락, 명시적 null, 형식 오류, 의미 미검증. 원문 문자열·알 수 없는 ID·식별자는 저장하지 않는다. 빈 배열도 의미가 검증되지 않은 버전에서는 실제 '없음'으로 단정하지 않는다.
- 지원 버전에서 의미를 확인할 수 있는 필드만 경기 사실로 표시한다. 미지원 버전에서 자료형만 맞는 값의 의미는 검증되지 않았으며, 현 근거로는 확인된 경기 사실로 보장할 수 없다. 미검증 후보값의 보관·표시를 허용할지는 A/B 검토와 개인정보 검사 후 확정한다. 이번 한 경기의 데이터 버전은 1~5 외이므로 최초 단계만으로 실제 경기 상세가 보인다고 약속하지 않는다.
- 수집과 동일한 응답을 사용하되 응답 재요청, 원문 디스크 기록 및 무제한 메모리 복사를 금지한다. 엄격 구문·중복·깊이·크기 검증, 취소·정리 및 기존 정상 수용/거절 계약을 유지한다. 기존 실패와 격리 보관 성공·실패는 서로 다른 상태로 알린다.
- 전용 저장소는 임의 로컬 식별자와 원자적 게시, 엄격한 경로·링크 검증, 개수·크기·보존 상한, 동시 접근, 손상·중단 복구·용량 초과 처리를 구체화한다. 정상 처리 인덱스를 재사용하지 않는다. 중복 여부를 보장하지 않는 '수신 기록'과 경기 해시 기반 중복 제거의 선택은 상세 안전 검수 후 정한다.
- 사용자 화면에는 저장된 읽기 가능한 정보와 각 항목의 상태, 선택한 참고 카탈로그와 미검증 안내를 함께 표시한다. 참고 카탈로그 선택은 기록의 실제 패치나 분석 자격을 바꾸지 않는다.

## 완료 조건 후보

합성 정상·결측·빈 배열·타입 오류·지원/미지원 버전·중복/손상 JSON·크기 제한·복수 문제를 다룬다. 비밀·개인정보 sentinel이 파일·로그·UI·예외에 나오지 않음을 확인하고, 저장 중 취소·전원 중단 모사·경로 공격·상한·동시 접근과 기존 카탈로그·정상 데이터 보존을 검증한다. 재실행 후 사용자 열람, 실제 집계·CSV 제외, 참조 카탈로그 상태 표시, Unity 소유 창 정리 및 실제 화면을 확인한다. 실제 API를 호출하거나 실제 저장 성공을 주장하려면 별도 승인과 증거가 필요하다.

## 외부 근거 재확인

2026-11-05 공개 [Riot Match History 문서](https://developer.riotgames.com/docs/tft#match-history)는 데이터 버전 1·2의 도입 이력을 설명하지만 이번 1~5 외 버전의 필드 의미를 확정하지 않는다. [개발자 이슈 #1185](https://github.com/RiotGames/developer-relations/issues/1185)는 다른 개발자의 Double Up 표본에 대한 미확정 제보이며, 이번 랭크 경기의 전체 양상이나 Riot의 공식 답변을 뜻하지 않는다. 실제 추가 경기 조회와 공개 댓글은 하지 않았다.

## 다음 행동

Antigravity 기획 A는 비식별 입력의 전송을 사용자가 승인한 뒤 Gemini 4 Argon Medium으로 실행되어 revise를 반환했다. 임의 ID·원문을 저장하지 않는 허용 목록, 미지원 버전의 의미 미검증 표시와 합성 유용성 확인, 단일 소비·원문 수명 최소화, 용량·기간·복구·개인정보 보호, 참고 카탈로그 배지의 구체화를 요구했다. 결과와 실제 요청은 `AntigravityCollab/tasks/2026-11-05-incomplete-match-planning/`에 기록했다. 현재 B와 세부 계약을 통합한다. 사용자의 기존 작업 및 Chrome·Unity 창을 보존한다.
