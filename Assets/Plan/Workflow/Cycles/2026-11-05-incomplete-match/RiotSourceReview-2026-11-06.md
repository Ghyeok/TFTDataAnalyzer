# Riot 공개 자료 확인 — 2026-11-06

목적: 실제 경기 API를 다시 호출하지 않고 불완전 경기 보관 설계에 필요한 공개 근거를 확인한다. 이 문서는 읽기 전용 조사 기록이며 외부 이슈에 댓글을 게시하지 않았다.

- [Riot TFT 개발자 문서](https://developer.riotgames.com/docs/tft)의 경기 내역 설명은 패치 9.19~9.22의 초기 `data_version` 1·2 이력을 설명한다. 여기서 현재 관측된 다른 버전의 정확한 의미나 누락 증강을 해석하는 규칙은 확인하지 못했다.
- [공개 제보 #1185](https://github.com/RiotGames/developer-relations/issues/1185)는 세트 18 EUW Double Up, 큐 1160의 제한된 표본에서 구체적 패치를 알 수 없는 `game_version`과 누락된 `augments`를 보고한다. 제보 작성자의 관측이며 Riot의 공식 원인 판정이나 큐 1100 전체에 대한 증거가 아니다. 확인 시 이슈는 열려 있다.
- [공개 제보 #1171](https://github.com/RiotGames/developer-relations/issues/1171)의 작성자는 원래 제기한 일부 참가자의 유닛·특성 누락이 해결됐다고 밝히고 이슈를 닫았다. 같은 이슈의 별도 댓글은 세트 18 랭크 경기에서 다른 필드와 버전 문자열 문제를 보고한다. 원래 문제의 종료를 다른 문제 전체의 해결로 해석하지 않는다.
- [공개 제보 #1187](https://github.com/RiotGames/developer-relations/issues/1187)은 세트 18 랭크의 피해량·처치 수 필드에 대한 별도 보고다. 현재 프로젝트의 실패 5건이 같은 원인이라는 근거는 아니다.

결론: 패치·증강이 확인되지 않은 값을 추정해 정상 통계에 넣을 공식 근거는 확인하지 못했다. 별도 보관 설계의 `누락`·`알 수 없음` 및 `의미 미검증` 표시와 통계 격리는 여전히 필요한 제안이다. 앞서 관찰한 실제 경기 한 건과 최초 실패 5건의 개별 원인은 계속 미확정이다. 사용자께서는 자동 삭제 없이 직접 정리하고 128건 도달 시 새 별도 보관을 중단하는 방향을 선택했다. 구체 구현은 아직 승인 전이다.
