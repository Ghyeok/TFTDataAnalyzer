# 데이터 관리 탭 사용 안내

날짜: 2026-10-16
상태: 구현·실제 검증·독립 QA 대조 완료, PR검수·사용자 최종확인은 별도.

`TFT Analyzer > Open Data Analyzer`의 데이터 관리 탭을 사용한다.

1. 로컬 카탈로그 행에서 세트·TFT패치·원본버전·출처 프로필·수집UTC·검증·hash·위치를 확인한다. 검증된 행을 선택하면 열린 창의 활성 카탈로그가 된다. 기존 형식 카탈로그는 검증해 읽으며 변환하거나 다시 저장하지 않는다.
2. 원본 버전 확인은 목록만 조회한다. 세트 ID/번호·TFT패치·원본버전은 직접 입력하며 자동 대응하지 않는다. 창을 열거나 탭을 바꾸기만 해서는 네트워크가 시작되지 않는다.
3. 필요할 때만 CommunityDragon 보충을 선택하고 카탈로그 가져오기를 누른다. 확인창의 전체identity·저장위치를 검토한 뒤 승인한다. 거절하면 다운로드하지 않으며 완료·거절·취소·실패 후 동의는 해제된다. 승인 중 위치가 바뀌면 다시 확인하도록 중단한다.
4. 실행 중에는 입력과 중복실행을 막는다. 작업 취소를 누르면 정리가 끝날 때까지 기다리며 이미 저장된 자료는 보존한다. 게시후 목록오류는 저장성공 사실과 복구안내를 함께 표시한다.
5. 검증된 로컬 카탈로그가2개 이상이면 이전/이후를 선택해 비교한다. 기물·시너지·아이템·증강의 추가/삭제/변경 수와 펼칠 수 있는 필드별 값을 확인한다. 수집시각 차이만으로 변경으로 표시하지 않는다.

활성선택은 같은 창의 화면재생성에는 유지하지만 창닫기/리로드 뒤 영속복원하지 않는다. 기존 정적 import 메뉴도 사용할 수 있다. 경기수집·통계·정책 탭의 실제 기능은 후속 작업이다.

실제 컴파일 오류0·집중23/23·loader11/11·전체410/410, 창과 최소크기 화면·보호해시1386개 유지 및 독립검수 통과를 확인했다. 실네트워크와 native확인창 클릭은 검증하지 않았다. 상세 [QA](QAReport.md), 재개 위치 [체크포인트](../Checkpoint.md).

다음 제품 작업은 Phase3 Task3 경기수집 탭 연결이며 이번 PR 검수 결과부터 처리한다.
