# 검토된 증강 분류 자료를 분석에 연결

2026-10-20. 상태: 승인 대기(최종 결과). 승인 기획의 구현·독립 코드검수·QA·실행을 마쳤으며 PR 최신 head 검수·병합·사용자 최종 결과 승인은 별도다.

## 이번에 구현한 기능

과거 경기의 비율 지표를 표시하려면 증강이 허용된 종류인지 검토된 자료가 필요하다. 이번에는 그 자료를 안전하게 읽어 분석에 전달하는 경로를 구현했다.

등록된 카탈로그·콘텐츠 해시와 승인 자료의 해시가 모두 맞을 때만 읽고, 형식·증강 ID·정책 종류를 끝까지 확인한다. 자료가 없거나 잘못됐으면 기존 정책 차단을 유지한다. 자료의 검토 여부를 임의 파일이나 체크박스로 선언할 수는 없다. 분석 탭의 기존 “로컬 집계 갱신”에서 동작하며 새 설정창이나 자동 수집은 없다.

**기본 승인 목록은 비어 있다.** 실제 Set18 증강의 분류 자료는 아직 확보·승인하지 않았다. 따라서 현재 사용자가 별도로 설정할 항목은 없고, 증강이 포함된 실사용 비율 지표의 차단도 유지된다. 자료 확보와 근거 검토·등록은 후속 과업이다. 이 기능의 합성자료 통과를 실제 분류 승인으로 해석하지 않는다.

- 공급 경로45/45·서비스7/7, 전체680개 중679통과·실패0·PC 링크 권한 제약1제외,89.23초다.
- 합성 경기100건의 승인 파일→익명 저장소→분석→CSV를 실제 실행했다. 표본99/100과 Legend/LegendBased/Unknown 차단도 유지됐다.
- 기존 창·프레임·포커스와 보호 파일1,389개가 그대로이며 임시 E2E 자산은 남지 않았다.
- 새 Console 오류0이며 개발 문서를 테스트 생성 파일로 보고한 경고1건을 보존했다. 문서는 실행 전에 root가 작성한 파일이고 초기 mtime 증거를 별도로 남겼다. 문서 후속 갱신 시각과 경고 원인 추정은 구분했다.
- 실제 API·수동 PNG는 미실행이다. [KI-001](../../../../../../docs/known-issues.md), 실제 분류 자료와 완전 일치 보드의 최소 표본 확보는 별도 후속 범위다.
