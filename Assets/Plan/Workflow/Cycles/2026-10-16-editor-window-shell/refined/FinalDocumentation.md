# 통합 분석 창 사용 안내

날짜: 2026-10-16
상태: 구현·실제 검증 완료, PR 검수·사용자 최종 확인은 별도.

상단 `TFT Analyzer > Open Data Analyzer` 메뉴에서 통합 창을 연다. 데이터 관리·경기 수집·과거 집계 분석·정책 안내 탭을 선택하면 해당 화면만 표시되고 과거 관측 고지는 유지된다.

현재 네 탭은 화면 목적과 준비 안내를 제공한다. 통합 창의 실제 데이터 관리·수집·분석 기능은 다음 작업에서 연결한다. 정적 데이터 가져오기는 기존 `TFT Analyzer > Data > Import Set 18 Patch...`를 사용한다. 창을 열거나 탭을 전환해도 다운로드·경기 수집·데이터 저장은 시작되지 않는다.

화면 파일이 없으면 경로를 알려주는 오류 안내가 표시된다. 해당 자산을 복구하고 창을 다시 열면 정상 화면으로 돌아간다.

컴파일 오류0, 신규 UI 테스트10/10, 전체 EditMode376/376 통과와 실제 메뉴·어두운 테마 화면을 확인했다. 상세 근거와 미실행 항목은 [QA](QAReport.md), 재개 위치는 [체크포인트](../Checkpoint.md)를 확인한다.

다음 제품 작업은 Phase 3 Task 2, 정적 데이터 관리 탭과 기존 가져오기 파이프라인 연결이다. 현재 PR 검수 결과를 먼저 처리한 뒤 이어간다.
