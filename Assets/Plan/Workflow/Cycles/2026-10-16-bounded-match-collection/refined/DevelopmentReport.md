# 제한된 경기 수집과 프로젝트 명칭 정리

날짜: 2026-10-16
상태: 구현·집중26/26·전체366/366 통과. PR과 물리 폴더 이동은 별도다.

## 구현

- MatchCollectionRequest는 전체 CatalogIdentity, 허용 플랫폼/큐/티어 라벨, 최대1~1000고유 경기 시도를 고정한다.
- EnvironmentSeedPuuidProvider는 환경 변수의 명시된 seed만 임시 메모리로 읽고 중복 제거한다. 최대100개·전체길이65536·항목길이512이며 제어문자·빈 항목·항목 내부 공백은 거부한다. 읽기 오류에 원문을 포함하지 않는다.
- MatchCollectionService는 최대10 ID페이지를 전체 seed가 공유한다. 페이지당100개, 상세 요청은 고유 ID마다 한 번이며 필터·실패도 시도 상한에 포함한다. 관측의 응답 해시·카탈로그·큐 대응을 검증한 뒤 저장한다.
- 응답은 메모리 내 엄격한 익명화 후 폐기한다. 취소 등록으로 활성 스트림을 닫고 다음 요청을 중단한다. 이미 확정된 관측과 저장소의 전역 중복 제거를 보존한다.
- 401/403/429·키 부재와 저장 오류는 중단한다. 목록의 다른 API 오류는 다음 명시 seed로, 개별 경기 API/파싱 오류는 다음 ID로 진행한다. HTTP 재시도는 기존 클라이언트에 위임한다.
- 수치/상태·UTC시각만 가진 불변 Summary/Progress를 사용하고 observer 예외는 폐기한다. 저장 오류의 확정 여부는 Failed로 보고하며 실제 파일에서 다음 실행에 복구한다.
- 프로젝트 표시 이름을 TFTDataAnalyzer로 변경했다. 사용자가 실제 폴더 이동까지 명시적으로 선택했으므로 C:/Unity/TFTDataAnalyzer로 이동한 뒤 검증할 예정이다. Markdown23개 파일의 이전 명칭을 현재 이름으로 정리했다. 과거 raw 기록의 경로도 사용자 요청에 따라 정규화했으며 실행 로그·Git 이력은 수정하지 않았다.

## 제한

UI/CSV·실제 API/키/seed·정책 분류 데이터·집계 자동 갱신은 실행하지 않았다. Explicit 네트워크 테스트는 asia의 사용자 지정 seed1개에서 ID1건 요청만 정의하며 기본 실행에서 제외한다. 티어는 검증된 개인 랭크가 아닌 사용자 지정 수집 라벨이다. 페이지 예산이 작아 첫 seed들에서 예산을 소비할 수 있으며 영속 커서/탐색 공평성·전수 수집은 보장하지 않는다. 저장 원자성·전원 차단·대규모 성능 보장을 기존 범위보다 확대하지 않는다. 기존 카탈로그와 사용자 Volume 변경을 보존한다.
