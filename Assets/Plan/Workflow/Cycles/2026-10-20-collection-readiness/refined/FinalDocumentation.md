# 수집 전 부족한 조건 안내

2026-10-20. 상태: 승인 대기(사용자 최종 결과). 기획 승인 범위의 구현·코드 검수·QA·문서 확인을 마쳤으며 PR 검수·병합을 완료했다고 주장하지 않는다.

## 바뀐 점과 사용법

카탈로그를 선택했는데도 계속 “카탈로그를 선택해 주세요”라고 안내하던 문제를 수정했다. 처음 수집하기 전에는 카탈로그, 지역·큐·티어 라벨·수집 상한, API 키와 수집 대상 설정을 순서대로 확인해 부족한 조건을 안내한다.

1. 데이터 관리에서 검증된 카탈로그를 선택한다.
2. 경기 수집에서 입력 조건과 하단 안내를 확인한다.
3. 키나 수집 대상 환경 설정을 준비했다면 “환경 설정 확인”을 누른다.
4. “입력 조건이 갖춰졌습니다”가 표시되면 “조건 확인 후 수집”을 누른다. 기존 확인 절차를 거쳐 수집한다.

준비됐다는 문구는 설정 존재와 입력 조건을 뜻하며 API 키 인증·서버 연결 성공을 뜻하지 않는다. 이미 실행한 작업의 성공·실패·취소 기록은 이후 입력이나 설정을 바꿔도 보존한다. API 키·수집 대상 값은 이 안내에 표시하지 않는다.

## 검증과 남은 범위

회귀11/11·관련65/65, 최종 전체631개 중630통과/실패0/호스트 링크 권한1제외다. 기존 창·프레임·포커스와 보호 파일1,386개가 그대로였고 테스트용 임시 자산도 남지 않았다. 수동 PNG와 실제 API는 실행하지 않았다. Console의 Unity 연결 도구 통신 오류2건은 별도로 남겼다.

[KI-001](../../../../../../docs/known-issues.md)의 간헐 가져오기 실패 원인, 실제 Riot API 수집, 기본 증강 신뢰 분류 공급과 최소 표본 확보는 후속 검증·기획 항목이다. 사용자 결정대로 KI-001 원인 규명을 이번 개발의 선행 조건으로 삼지 않았다.

## 실행 비용·다음 행동

root가 구현·Unity 실행·문서를 담당했고 기존 기획 B·코드 검수·QA 담당을 재사용했다. 신규 에이전트0이며 같은 검토를 반복 호출하지 않았다. Antigravity A는 실제 기록 기준10,667토큰·응답31.65초(호출 전체40.14초), 추가 기획 A 호출0이다. GPT 역할의 실제 모델/추론·개별 토큰·비용은 확인 불가다. 전체 테스트는 동결 후1회 실행했다.

코드와 문서를 함께 커밋해 PR을 제출한다. push 후 자동 재조회·주기적 AI 호출은 하지 않으며 Hermes 검수 예약도 중단을 유지한다. 사용자가 재개하면 최신 head 검수·미해결 항목·CI를 확인하고 기존 승인 범위를 따른다. 사용자의 최종 결과 승인 전에는 이 사이클 전체를 완료 처리하지 않는다.
