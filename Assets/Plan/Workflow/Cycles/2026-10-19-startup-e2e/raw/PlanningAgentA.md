# Task6 범위·완료 조건 검토

판정: 수정 필요. 초안은 기존 Task6의 24시간 버전 목록 조회, 수동 가져오기, 두 경기 전체 흐름과 Phase3 조건을 대체로 유지한다. 아래 계약을 확정하면 구현 범위 확대 없이 진행할 수 있다. PR13 최신 head 통과·병합 전 제품 변경 금지, 모니터 예약 중단을 유지한다.

1. **24시간 상한**: 상태 저장 실패 후 요청하면 재로드마다 재시도되어 상한을 보장할 수 없다. 시도 시각을 원자적으로 저장한 뒤에만 전송하고 저장 실패는 고정 오류로 종료하도록 확정한다. 손상은 한 번 복구 저장 후 검사, 미래 시각은 현재 UTC로 보정하고 24시간 대기한다. 전송 전 취소는 시도 미소비, 저장 후 취소·실패는 시도 소비로 정한다. 반복 자동 재시도 기능은 추가하지 않는다.

2. **안내와 비교 기준**: 기존 데이터 탭의 수동 가져오기 영역에 수동 승인 필요 안내를 비차단 방식으로 표시하며 창 자동 생성·탭 전환·포커스 이동을 금지한다. 창이 없으면 상태만 유지하고 다음 열기에 표시한다. 마지막 가져옴은 검증된 manifest의 실제 수집UTC 최댓값과 전체 카탈로그 식별자로 결정하고 동률은 결정적으로 처리한다. 활성 선택 변경은 기준을 바꾸지 않는다. 카탈로그 없음은 업데이트 차이 안내 대신 기존 가져오기 안내를 유지한다.

3. **실제 E2E 경계**: 임시 프로젝트형 루트에 실제 pipeline·publisher·index·관측 저장소·집계·분석 binding을 연결한다. 루트/전송/시계만 주입하고 핵심 처리 결과를 mock하지 않는다. 승인 UI의 확인/취소와 두 경기에서 실제 산출된 행·익명 파일까지 하나의 통합 경로로 단언한다. 수집 승인도 명시해 정적 가져오기 승인만으로 대체하지 않는다. Generated/Library 기본 경로 우회나 단위 테스트 묶음은 완료 증거가 아니다.

4. **통계·동의·개인정보**: 두 경기 행은 표본 부족으로 비율·구간을 숨긴다. 별도 99/100 실제 표시 검증에서 표본 수·95% Wilson 구간·최소값100 강제·CSV 억제를 확인한다. 매 가져오기 CommunityDragon 해제, 승인 취소 후 다운로드·게시 없음, 식별자·가짜 키의 파일/로그/UI 미노출을 명시한다. 분석 snapshot만으로 두 경기 전체 흐름을 대신하지 않는다.

5. **최종 감사 구체화**: Phase1/2를 포괄 문장으로 끝내지 말고 전체 식별자/원본 버전과 TFT패치 분리, 덮어쓰기 방지·검증 실패 복구, 익명화·중복 수집·호출 제한, 지역/티어/큐 분리·기간/분모, 금지 지표와 로컬 CSV를 현재 테스트에 대응시킨다. 새 기능 추가가 아니라 기존 조건의 증거 연결이다.

완료 증거는 최종 head의 전체 EditMode·컴파일/Console, 가짜 전송 요청 기록, 수동 전체 흐름 PNG, 보호 파일 해시, 기존 창/프레임·포커스 보존 및 소유 잔류0으로 구분한다. 실제 Player 빌드와 콜백 검증, 선택적 실제 네트워크 검증은 구별한다. 본 검토는 문서 대조이며 실행 통과가 아니다. 실제 모델·추론·사용량은 확인하지 않았다.
