# 최근 가져오기 보고서 사용법

2026-10-21. 상태: 승인 대기. 승인 범위 구현·코드검수·전체765개763통과/실패0/호스트2제외, 실제4PNG검증과 최종QA pass 후 PR 검수/병합 대기다. 사용자 최종 결과 승인은 별도다.

데이터 관리 탭에서 정적 카탈로그 가져오기를 실행한 뒤 ‘최근 가져오기 보고서’를 펼친다. 이번 창의 가장 최근 실제 실행 요청과 시작 UTC, 게시 여부, 검증 오류·경고를 확인할 수 있다. 보완을 허용한 실행은 공식 값과 보완 값, 공식 값 유지 또는 빈 필드 보완 결정을 표시한다.

각 상세는20행씩 넘긴다. 각각 최대200행만 보유하고 전체 건수와 달라지면 ‘일부 상세 누락’을 표시한다. 각 값은512자까지 표시하며 생략을 알린다. 태그처럼 보이는 원문도 일반 글자로 표시한다. 페이지 이동은 다운로드를 실행하지 않는다.

버전 확인·입력 변경·가져오기 승인 거절은 지난 보고서를 유지한다. 실제 새 실행을 시작하면 새 요청으로 교체한다. 취소/오류로 결과를 받지 못한 경우 ‘상세 보고서 없음·게시 여부 미확인’이며0건/게시 성공으로 해석하면 안 된다. 게시 후 목록 복구 문제가 발생하면 기존 상태 안내를 따른다. 검증 거절 결과는 원인을 읽을 수 있지만 차단을 해제하지 않는다.

보고서는 창 세션의 메모리에만 남고 창을 닫으면 사라진다. 기존 로컬 카탈로그를 선택하는 것만으로 과거 가져오기 보고서를 복원하지 않는다. 별도 파일 저장·내보내기는 추가하지 않았다. 실제API·실제증강분류·실제n100검증은 별도 남은 과제다.
