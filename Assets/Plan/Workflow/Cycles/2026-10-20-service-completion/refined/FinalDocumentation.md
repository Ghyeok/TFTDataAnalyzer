# 카탈로그 내용 탐색 사용법과 결과

2026-10-20. 상태: 구현·코드검수·QA 완료 시점의 결과. 최신 외부 PR검수·병합은 별도 확인한다.

데이터 관리 탭에서 검증된 카탈로그를 선택한 뒤 **카탈로그 내용 탐색**을 펼친다. 종류를 고르고 한국어·영어 이름 또는 ID를 입력하면 해당 자료를 찾는다. 목록은50개씩 표시하며 이전/다음 페이지로 넘긴다. 항목을 선택하면 한영 이름·설명, 기존 속성·효과·관계·출처와 아이콘을 읽을 수 있다.

자료가 없으면 ‘자료 없음’으로 표시한다. 관계 대상이 없거나 여러 종류에 있으면 원래 ID와 종류를 구분한다. 한국어가 없으면 영어로 대체했음을 알리고, 옛 출처의 정규화 기본 날짜를 실제 수집일로 표시하지 않는다. 화면 재구성은 검색과 선택을 보존하고, 활성 카탈로그를 바꾸면 이전 상세를 지운다.

검색·상세 보기는 로컬 카탈로그만 사용한다. 새 다운로드·경기 수집·집계 저장을 실행하지 않는다. 카탈로그에 수록됐다는 사실이 해당 패치의 실제 경기 등장이나 증강 통계 허용을 뜻하지 않는다. 실제 분류 자료는 아직0개이며 기존 비율 차단과 표본100하한을 유지한다.

검증은 관련 UI169/169, 전체701개 중700통과·실패0·PC 링크 권한 제약1제외다. 실제940/500px 네 화면과 정상/표시 전후 예외 정리를 확인했다. 기존 창·프레임·포커스와 보호 파일1,389개를 보존했다. 새 Console 오류는 없고 문서 인식 경고1건은 기록했다. 실제 API·정책 자료 승인·KI-001 해결·실제 표본 검증은 별도다.

사용자가 승인한 현재 목표에 따라 최신 head의 CodeRabbit·남은 의견·CI를5분 간격으로 확인하고 조건이 충족되면 main에 병합해 다음 계획으로 진행한다. Hermes 예약은 재등록하지 않는다. 전체 서비스 목표에는 실제 분류 자료·API 검증·표본 검토 등 남은 작업이 있으며, 이번 탐색 기능만으로 목표 완료를 선언하지 않는다.
