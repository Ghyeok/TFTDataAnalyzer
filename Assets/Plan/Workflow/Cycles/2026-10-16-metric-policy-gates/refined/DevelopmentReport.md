## 결과

`MetricPolicy`는 `AggregateMetric`과 `PairwiseMetric`을 같은 기준으로 검토한 뒤 `Visible`, `InsufficientSample`, `PolicyBlocked` 결과를 만든다. `MetricPresentation`은 원본 집계나 관측을 참조하지 않으며, 허용된 수치와 고정된 과거 통계 용어만 전달한다.

- 최소 표본은100으로 고정하고 설정값으로 높일 수 있다. 미달하면 평균 순위·표본 수는 남기되 비율 목록을 비워 분자·분모·신뢰구간도 출력에 남기지 않는다. 상대배치의 제외 로비는 적격 표본에 더하지 않는다.
- LegendBased는 비율을, Legend는 평균도 차단한다. 금지 정책은 표본 부족 판정보다 우선한다. 알 수 없는 증강 ID는 고정 오류 코드로 차단하고 원문을 노출하지 않는다.
- 기존 집계에는 조합 해시만 있어 정책 관련 증강을 복원할 수 없었다. 빌더에서 각 조합 및 쌍 양쪽에 정렬·복사된 증강 ID를 연결하고, 집계 스키마2로 저장한다. 기존 스키마1 캐시는 변경하지 않고 관측에서 재생성해야 한다. 정적 카탈로그와 관측 형식은 변경하지 않았다.
- StaticCatalog에는 정책 분류가 없다. `MetricPolicyMetadata`는 선택한 전체 카탈로그 식별자와 세트 번호에 묶인 검토된 명시적 분류를 복사한다. 누락/불일치/Unknown은 비율 차단이며, 이름이나 설명에서 분류를 추측하지 않는다. 이번에는 가짜 분류만 검증했고 실데이터 분류 파일·자동 등록 흐름은 추가하지 않았다.
- 카탈로그·출처 프로필·세트 번호가 다른 경우 출력 scope와 값을 차단한다. 지역·티어는 정해진 라벨만, 큐는 양의 숫자만 허용해 임의 식별 문자열을 출력에 되돌리지 않는다.
- DTO는 opt-in 읽기 전용 속성을 사용한다. `ToJson`은 별도 serializer를 생성하므로 전역 JSON 타입/변환 설정을 상속하지 않는다. 이 API는 데이터/문자열만 반환하며 UI나 파일 내보내기는 연결하지 않았다.

## 판단과 제한

1. 이번 정책은 저장소에서 승인한 규칙의 구현이다. 현행 외부 정책·제품 등록·배포 적합성을 새로 검증했다고 주장하지 않는다. 외부 제공 전에 별도 검토가 필요하다는 기존 설계는 유지한다.
2. 분류 메타데이터의 실제 근거·승인·갱신은 통합자의 신뢰 책임이다. 임의로 Standard를 붙인 값을 진실로 증명하는 API가 아니다. 실데이터 분류 연결 전에는 증강을 포함한 정상 조합도 비율이 차단될 수 있다. 카탈로그는 기존 불변 식별 계약을 신뢰한다.
3. raw 집계 캐시는 내부 계산 자료다. 사용자 화면·내보내기는 반드시 정책 DTO를 사용해야 하며 향후 소비자의 임의 raw 직렬화를 강제로 막는 격리 경계는 아니다. 허용된 평균·표본 수로 가능한 모든 통계적 추론을 막는다고 주장하지 않는다.
4. 기본 지역은 asia/americas/europe, 티어는 명시한 순위·구간 라벨, 큐는1–6자리 양의 숫자다. 맞춤 필터 라벨은 정책 API를 확대하기 전까지 차단된다. 실제 UI 입력 선택지는 아직 구현하지 않았다.
5. 집계 스키마2는 증강 ID 출처를 보관한다. 자동 캐시 이관·집계 로더·삭제·실데이터 재생성은 실행하지 않았다. 구형 캐시를 출처가 없는 빈 증강 목록으로 해석해서는 안 된다.
6. 기존 저장의 원자성·전원 차단·대규모 성능·악의적 로컬 경합 보장은 확대하지 않는다. 실제 수집 서비스·인증·UI·외부 파일 내보내기·실서비스 호출도 이번 범위 밖이다.

실행 주체는 Codex다. 루트 실제 모델·추론·사용량·시간은 독립 확인할 수 없어 추정하지 않는다. 데이터/개인정보 경계 독립 검수에는 `gpt-6-astra` · High를 요청했다. 구현 후 집중·전체 검증과 독립 검수를 통과했으며 제품 코드 재작업은 없었다. 검수자가 판단을 유보한 현행 외부 정책·실제 분류·미래 소비자/구형 캐시 리더·허용 평균의 추론은 위 제한에 남긴다. 실행 결과·보존 해시는 구현자가 직접 확인하며 검수 의견으로 대체하지 않는다.
