# 기획 A 통합안 재검토

제공된 비식별 통합 계획만 검토한다. 이전 검토에서 요청한 미지원 버전의 의미 미검증, 통계 격리, 개인정보, 수집 실패 및 제한된 보존이 반영되었는지 확인한다. 30일 자동 삭제와 128건 상한은 사용자에게 아직 확정받지 않은 제안이며, 이를 기정사실로 취급하지 말고 사용자 선택과 데이터 보존 위험을 검토한다. 합성 검증과 실제 API 검증의 차이를 유지한다. 제공 텍스트 밖 도구·파일·네트워크·재위임을 사용하지 말고 schema의 taskId/inputDigest를 유지한다. 실제 접근 차단은 검증되지 않았다.
