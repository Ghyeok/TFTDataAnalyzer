# 조합 기준 변경: 사용자 확정 범위

기준 제품 트리 `8352753584913b0b99a0bc635d6b58fb2ef2c5f5`, main `d186d39158ee011e3ef2fcbbc42b0804e3fcbb03`. 별도의 정적 카탈로그 PR #28은 검수 중이다. 실제 Riot 경기 원문·키·개인정보는 이 기획 입력에 없다.

사용자 결정: 같은 조합은 **경기 종료 시점**의 기물 목록과 활성 시너지 종류가 일치할 때다. 기물 성급, 기물에 장착한 아이템, 증강은 조합을 구분하지 않는다. 실제 마지막 전투 참가 여부를 확인할 수 없어 사용자가 종료 시점 기물 목록 사용을 선택했다. 활성화 여부는 현행 `TierCurrent > 0`, 활성 시너지는 종류를 비교하고 구간은 조합을 구분하지 않는다. 기물 중복 수 보존 여부와 원본에서 확인 불가능한 대기석 등은 확인된 자료에 한해 취급하고 추정하지 않는다.

아이템·증강 필터는 유지한다. 사용자가 조건을 선택하면 그 조건에 맞는 경기의 참가자 관측을 대상으로 해당 통계를 다시 계산한다. 두 필터가 함께 선택되면 같은 참가자 관측에 함께 해당해야 한다. 필터 미선택 시 모든 변형의 참가자 관측을 포함한다. 지역·큐·티어 기록 라벨·기물·시너지 조건은 기존 의미를 유지하되 혼동 없이 일관되게 적용한다. 최종 개별 기물의 아이템·증강은 원본 익명 관측에 보존하지만 집계된 모든 관측의 공통값으로 표시하지 않는다.

패치·세트·원본 버전·출처·지역·큐·티어의 분리, 최소 표본 100, 증강 정책 분류와 Legend 제한을 약화하지 않는다. 식별 가능한 경기 원문·API 키는 저장하지 않고 실제 API 호출은 범위 밖이다. 기존 사용자 카탈로그·익명 관측과 기존 파일을 보호한다. 동률·같은 조합 다수 출현 등 상대 배치 비교의 기존 제외 정책도 보존하되 새 조합 기준에서 다시 검토한다.

기획 A/B는 같은 입력을 독립 검토하여 개인정보·정책·표본·데이터 손상·마이그레이션·표시 신뢰·성능·취소·테스트 우선순위와 미확정점을 제시한다. 외부 문서·도구·네트워크·재위임은 사용하지 않는다. 사용자 확정을 번복하지 않고 미확정 사항은 구분한다.
