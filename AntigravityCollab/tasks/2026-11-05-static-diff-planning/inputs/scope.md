# 정적 카탈로그 비교 표시 보완

기준 main ba50db8. 목표 2번: 패치 비교의 이전·이후 값을 사용자가 정확히 읽는다. 이미 기물·시너지·아이템·증강 검색과 추가·삭제·변경 계산은 구현되어 있으므로 새 검색/비교 계산을 만들지 않는다.

현재 화면은 외부 원본에서 온 필드명·값과 안정 ID를 Label과 Foldout 제목으로 직접 넣는다. 기존 탐색/가져오기 보고서와 달리 비교 화면에 rich text 비활성화가 없어 `<color=#00000000>Before</color>` 같은 실제 원본 문자열이 서식으로 해석되어 값이 숨겨질 우려가 있다. 합성 자료로 동작 경계를 확인하고 리치 텍스트 없이 원문을 보여준다. 기존 선택·전후 방향·재비교·카탈로그·계산·저장·실제 API는 유지한다.

현재 비교 데이터의 목록/효과/출처는 내부 제어 구분자로 이어져 있다. 이 구분자가 현재 화면에서 사용자에게 제대로 읽히는지도 확인하고, 사실관계가 입증되면 표시 계층에서 목록의 경계만 읽기 쉽게 제시하는 방안을 별도 세부 계약으로 검토한다. 임의 원문·문자/값을 변형하거나 원본 스키마를 변경하지 않는다.
