# 수집 실패 사유 안내 기획 입력

기준 커밋 6a6f787d5ec5346f92bfdd5c605715d4df6e97e6. 사용자는 실패 건수뿐 아니라 확인 가능한 실패 이유를 화면에 구분해서 보여 달라고 요청했다. 실제 5건은 각 원인 미기록이므로 소급하여 추정하지 않는다. 새 수집에서만 확인한 고정 범주와 건수를 표시한다. 정상 저장, 필터, 실패의 기존 판정과 정책은 유지하며 실제 API 자동 호출은 추가하지 않는다.

범위 후보: 읽을 수 없는 경기 형식, 지원하지 않는 데이터 버전, 증강 정보 누락 또는 잘못된 형식, 게임 버전 확인 불가, API 및 저장/기타 오류. 진단이 확실히 근거를 확보한 항목만 분류하고 미확인은 일반 오류로 처리한다. 여러 문제가 있어도 첫 확정 실패만 세어 중복 건수를 막거나 별도 명료한 표기를 사용한다. 식별자·원본 응답·임의 문자열·예외 메시지·API 키는 표시·기록하지 않는다. 취소·재시도·이전 결과 보존은 기존 동작을 유지한다.

사용자는 불완전 경기의 별도 익명 보관, 빈 값과 알 수 없음 구분, 확인 필요 표시, 통계와 격리, 사용자 선택 참고 카탈로그 방향을 별도로 확정했다. 이 작업에서는 설계 방향만 기록하며 해당 저장·변환·재처리·카탈로그 연결을 구현하지 않는다.
