# 기획 A: 안전 진단과 수정 범위 검토

제공된 두 입력만으로 제품 가치·정책·개인정보·실제 경기 유효성·기존 데이터 보존·진단 승인 범위와 완료 기준을 독립 검토한다. 개인 정보와 실제 응답을 요청하지 않는다. 비대상 경기와 실제 지원 대상 판별 근거 부족, 누락 증강을 빈 배열로 추정하는 위험, 증거 없는 data_version 허용 및 반복 요청을 중점 확인한다. 상충하는 기획이 있으면 문제와 최소 수정안을 제안하고 필수 사항을 최대 6개로 보고한다. 제공된 text 외 저장소·네트워크·도구·파일·재위임을 사용하지 말고 제공 schema의 taskId/inputDigest를 유지한다. 실제 접근 차단은 별도 미검증이다.
