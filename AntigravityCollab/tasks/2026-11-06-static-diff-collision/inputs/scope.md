# 정적 카탈로그 비교의 구분자 충돌

기준 main ba50db8. 정상 카탈로그 비교에서 관계 ID 목록·효과 사전·출처 목록을 충돌 가능한 제어문자 연결 문자열로 판정해 서로 다른 입력을 같은 값으로 취급할 수 있다. 실제 Unity CatalogDiffer와 CatalogValidator에서 각각 3개 합성 사례를 실행했고 양쪽 오류 0이나 변경 항목이 0이었다. 실제 카탈로그에서 발생했다는 근거는 없다. 목표는 자료 구조의 차이를 감지하고 사용자가 화면에서 이전·이후 값을 구별하도록 하는 것이다.

카탈로그·기존 파일/해시·정상 데이터는 수정하지 않는다. 기존 공개 FieldChange와 일반 이전/이후 문자열의 호환, 순서·중복의 기존 의미, 조회 시각만 다르면 무시, 사용자에게 정확한 변경 표시를 유지한다. 원본에 포함된 제어문자를 금지하거나 연결된 문자열을 역분해하지 않는다. 제품 외부 API 요청은 없다. 이전 1번 수집 실패 이유와 3번 불완전 경기 저장은 범위 밖이다.
