# 불완전 경기의 익명 보관 기획 입력

기준 main ba50db8ad5ef8dc6ef58153cee57da0f8555588c. 사용자는 읽을 수 있는 경기 정보는 익명으로 별도 보관하고 없는 값과 알 수 없는 값을 구분해 추가 확인 필요로 표시하기로 했다. 사용자가 선택한 기존 카탈로그를 참고용으로 함께 볼 수 있으나 경기의 실제 패치로 단정하지 않는다. 복구 불가능한 정보는 알 수 없음으로 유지한다.

실제 관측 한 경기: 세트18 및 큐1100 일치, game_version 숫자 패턴 불일치, data_version은 1~5 외, 참가자 중 augments 미제공. 최초 실패 5건과 동일 경기인지는 모른다. 실제 API 추가 호출은 승인되지 않았으며 이 기획과 기본 검증은 합성 자료만 사용한다. 키·PUUID·경기 ID·원본 응답·식별 정보는 보관하거나 출력하지 않는다.

목표: 정상 통계와 격리된 비식별 읽기 전용 기록을 사용자에게 실제 유용하게 표시하는 가장 작은 안전한 단계를 제안한다. 단순 오류 보고만 반복하지 않는다. 불완전 데이터가 자동으로 정상 저장·집계/CSV에 들어가거나, 세트/날짜로 임의 패치를 추정하거나, 증강 미제공을 빈 목록으로 해석하지 않는다. 미지원 data_version의 필드 의미를 확인할 근거가 없는 경우 이를 진실한 경기 사실로 표현하지 않는다. 해당 데이터가 실제로 저장 가능한지는 미확인이다.

선행 설계의 명시 승인과 독립 검수·QA, 기존 카탈로그 및 정상 저장 파일 불변, 같은 오류 근거 없는 반복 금지, 소유 EditorWindow의 예외·종료 정리 및 개인 데이터 누출 방지가 필요하다. 기존 카탈로그 내용·저장소·환경 변수를 변경하지 않는다. 검수 요청은 입력 두 파일만 이용한다.
