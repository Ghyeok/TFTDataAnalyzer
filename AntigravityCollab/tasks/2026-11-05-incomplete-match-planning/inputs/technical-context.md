# 현재 기술 계약

MatchAnonymizer는 크기 8MiB 제한과 엄격한 JSON 문법·중복 필드·깊이·자료형 검사 후 요구 DTO를 파싱한다. data_version 2, 식별 가능한 게임 릴리스 및 활성 카탈로그와 일치하는 세트/릴리스, 8인 로비, 증강 배열 등 조건을 만족하지 않으면 일반 관측을 만들지 않는다. 새 진단은 첫 확정 실패 이유만 반환하며 여러 부족 정보를 보관하지 않는다. DTO 실패 후 같은 스트림 재파싱은 원문·동작 회귀의 별도 위험이다.

ObservationStore는 검증된 익명 관측의 NDJSON, 경기 ID의 도메인 구분 해시, 중복 인덱스·복구·임시 꼬리 제거·경로 reparse point 방어·취소·원자적 실패를 사용한다. catalog identity로 구획되며 AggregateBuilder/CSV는 정상 관측과 결합한다. AnonymousParticipant는 null augment를 빈 목록으로 바꾼다. 따라서 불완전 기록은 다른 자료 모델·경로로 분리해 기존 ObservationStore, 분석, 통계, CSV, 처리 인덱스에 섞이지 않아야 한다. 같은 경기의 격리/정상 중복 및 승격은 별도 명시가 필요하다.

불완전 기록의 입력은 ID·PII·원본 JSON을 포함할 수 있다. 미지원 schema에 대한 허용 필드·타입·표현/검증, 불명확한 필드의 출처 및 확실성, 보존 기간·용량/행 수 상한·중복·동시 쓰기·중단·원자적 저장·손상 복구·경로 공격, 원문 값/로그/식별정보 탈출 금지, 미확인 ID의 출력 위험을 검토한다. 새로운 UI는 사용자 보유 기존 카탈로그에서 로컬 조회하며 참조용·미확인 상태가 명확해야 한다. 진행 단계마다 사용자가 이득을 얻는 최소 범위와 세부 테스트 및 이관/승격을 독립적으로 판단한다.
