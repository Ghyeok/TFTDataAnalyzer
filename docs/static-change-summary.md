# 정적 카탈로그 변경 요약

데이터 관리 탭에서 새 카탈로그를 가져올 때 **변경 요약 기준**을 고르면, 새 자료와 선택한 로컬 자료의 차이를 요약합니다. 기준을 선택하지 않으면 요약 없이 가져옵니다.

1. 비교에 사용할 카탈로그를 먼저 로컬에 준비합니다.
2. 가져올 세트·TFT 패치·원본 게임 버전과 출처를 입력합니다.
3. **변경 요약 기준**에서 같은 세트와 출처를 가진 다른 카탈로그를 선택합니다. 비교 방향은 선택한 기준에서 새 카탈로그 방향입니다. 자동으로 실제 직전 패치를 판단하지는 않습니다.
4. **카탈로그 가져오기**를 누르고 확인 창에서 대상과 기준을 확인합니다. 가져오기는 해당 버튼을 직접 눌렀을 때 시작합니다.
5. 로컬 목록에서 가져온 카탈로그를 선택하면 기물·시너지·아이템·증강의 추가·변경·삭제 건수가 나타납니다. 자세한 차이는 기존 **카탈로그 변경 비교**에서 두 자료를 골라 확인합니다.

기준 파일이 변경되거나 없어지면 다시 선택해야 합니다. 저장된 요약을 다시 확인할 기준이 없을 때는 재검증할 수 없다고 표시합니다. 이미 저장된 같은 카탈로그를 재사용하면 기존 파일과 요약은 그대로 유지됩니다. 이전에 저장된 카탈로그에는 요약을 소급해서 쓰지 않습니다.
