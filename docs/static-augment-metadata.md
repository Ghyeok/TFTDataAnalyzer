# 공식 증강 메타데이터 가져오기

Riot Data Dragon 증강 문서의 최상위 `augment-container`는 카탈로그 레코드가 아닌 부가 정보다. 문법을 확인하고 이 객체를 제외한 뒤 `data`를 읽는다. 객체 내부의 중복 속성 값을 선택하거나 카탈로그에 반영하지 않으며, 해당 부가 정보를 제외했다는 경고를 가져오기 보고서에 한 번 표시한다. 게시 마니페스트에는 경고 건수만 기록된다.

증강 문서의 최상위 키와 다른 객체, 실제 `data` 내부의 중복은 여전히 오류다. 기물·시너지·아이템 및 보완 원본의 파서는 변경하지 않았다. 증강 문서의 길이는 최대 16 Mi 문자이고 중첩은 최대 64단계이며, 비표준 JSON 및 문서 끝의 추가 내용도 거부한다. 원본의 해시는 수정 전 HTTP 응답을 기준으로 계산하며 기존 원본 보관 경로에는 응답이 그대로 남을 수 있다.

2026-11-12 검증에서는 16.22.1의 한·영 공식 정적 원본을 사용해 테스트 전용 임시 경로에 official-only 카탈로그를 게시했다. 원본 증강 목록은 언어별 760건이고 기존 세트 선택 규칙의 대상은 487건이었다. 선택된 ID와 게시된 ID를 비교한 결과 누락과 추가가 없었고 게시 해시가 일치했다. 이미지 응답은 테스트용 자료로 대체했으므로 실제 이미지 다운로드는 이 실험의 검증 범위가 아니다. CommunityDragon 결합 경로와 사용자가 기존 창에서 직접 실행하는 과정은 실제 16.22.1 자료로 확인하지 않았다. 임시 게시 실험은 기존 카탈로그를 대상으로 하지 않았지만 기존 카탈로그의 사전·사후 해시 대조는 수행하지 않았다.

자동 검증은 관련 정적 수집·게시 테스트 56건을 실행해 모두 통과했다. 변경이 공통 파서가 아닌 공식 증강 문서 처리로 한정되어 전체 테스트는 실행하지 않았다. 실제 공식 자료 파싱·임시 게시와 테스트 데이터의 오류·경고 검증을 구분하며, 경기 API는 사용하지 않았다.
