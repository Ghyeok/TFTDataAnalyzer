# 불완전 수신 기록

정상 경기 저장 조건을 충족하지 못한 응답에서 안전하게 확인할 수 있는 값은 별도 기록으로 보관할 수 있다. 경기 수집 탭의 **불완전 수신 기록**에서 새로 확인하고 선택해 상세를 열거나 삭제한다. 이 기록은 정상 관측, 집계 및 CSV에 포함되지 않는다.

필드의 누락·null·빈 배열·형식 오류와 의미 미검증은 구분한다. 선택한 카탈로그가 검증되고 기록의 참고 카탈로그와 일치할 때만 관련 ID와 이름·설명을 표시한다. 카탈로그는 참고 자료이며 실제 경기 패치의 증명이 아니다. 원본 응답, API 키, 사용자 식별자, 경기 ID 및 임의 응답 문자열은 기록하지 않는다. 중복 확인용 별도 해시는 기록을 연결할 수 있으므로 제한된 로컬 자료로 취급한다.

기록은 최대 128건, 건당 256KiB까지 보관하고 자동 삭제하지 않는다. 상한에 도달하면 선택 삭제 후 필요한 경우 수동으로 다시 수집한다. 기존에 버려진 응답의 누락된 값을 복구하거나 실제 데이터가 저장될 것을 보장하지 않는다.
