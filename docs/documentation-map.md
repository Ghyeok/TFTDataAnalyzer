# 프로젝트 문서 안내

이 저장소는 현재 사용 안내와 작업 당시의 근거를 함께 보관한다. 문서의 날짜·상태와 현재 코드, Git 및 실행 결과를 구분해서 읽는다.

## 현재 안내

- [README](../README.md): 제품 범위, 현재 사용할 수 있는 기능과 사용법.
- [알려진 문제](known-issues.md): 미해결 문제와 확인된 한계.
- [작업 지침 색인](agent-guides.md)과 [AGENTS.md](../AGENTS.md): 현재 작업 규칙과 상세 지침의 진입점.
- [개발 워크플로](../Assets/Plan/Workflow/README.md): 기획·구현·검수·QA의 역할과 기록 규칙.
- [제품 설계](../Assets/Plan/TFTDataPipeline.md)와 [구현 계획 색인](../Assets/Plan/Implementation/TFTDataAnalyzerImplementationPlan.md): 제품 경계와 단계별 설계. 계획 문서의 날짜별 상태는 당시 이력이다.

## 과거 작업과 협업 자료

- `Assets/Plan/Workflow/Cycles/`의 날짜별 `Checkpoint.md`, `refined/`, `raw/`는 각 사이클의 결정과 실행 증거다. 옛 체크포인트의 ‘현재’와 테스트 결과를 오늘의 상태로 적용하지 않는다. 관련 작업을 재개할 때는 더 새로운 기록과 실제 코드를 확인한다.
- `AntigravityCollab/tasks/`는 요청·입력·응답을 보존하는 협업 기록이다. 특히 `inputs/`의 복사본과 manifest 해시는 검수 당시의 자료이므로 중복처럼 보여도 수정하거나 삭제하지 않는다. 복사된 문서의 상대 링크는 원본 위치가 아니라 복사 위치에서 열리므로 작동하지 않을 수 있다.
- `HermesCollab/`는 별도 협업 전달 경로다. Git에서 제외된 개별 작업 폴더는 새 복제본에 없을 수 있다. 과거 예약이나 실행 기록이 현재 예약 상태를 뜻하지 않는다.
- `Library/`는 Git에 포함되지 않는 로컬 캐시·진단·검증 산출물이다. 다른 컴퓨터에서 파일이 존재하거나 과거 결과가 현재 상태를 증명한다고 가정하지 않는다.

과거 실행 기록은 문제 재현과 검수 근거로 쓰일 수 있으므로, 단순히 오래됐다는 이유만으로 삭제하지 않는다. 더 이상 현재 상태가 아닌 내용은 이력으로 표시하거나 최신 문서로 연결한다.
