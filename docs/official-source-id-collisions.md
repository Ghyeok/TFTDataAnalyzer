# 공식 정적 자료의 ID 충돌 처리

Riot Data Dragon의 같은 종류·같은 언어 문서에서 서로 다른 원본 항목이 같은 ID를 사용하면, 항목 하나를 임의로 선택하지 않고 모든 원본 행의 세트 범위를 먼저 확인한다. 한국어와 영어에서 같은 ID를 사용하는 것은 정상 번역 연결이다.

선택한 세트의 항목이 관련되거나 범위가 불명확한 충돌은 오류로 표시하고 카탈로그 게시를 중단한다. 모든 관련 행이 동일한 다른 세트에만 속한다고 확인되면 해당 ID 그룹 전체를 제외하고 경고한다. 보고서에는 항목 종류·언어·ID와 원본 키를 제한된 길이로 표시하며, 충돌이 많으면 오류 상세를 우선 표시하고 총 건수와 생략 여부를 알린다. 원본 해시와 기존에 게시한 카탈로그는 바꾸지 않는다.

실제 16.22.1 한·영 공식 자료에서는 중복 ID가 없었고, 이 변경 후 캐시된 원본의 기물 74·시너지 36·아이템 523·증강 487건과 기존 증강 ID가 유지됐다. 합성 충돌·기존 게시물 보존 관련 테스트는 54건 모두 통과했다. 별도의 전체 EditMode 실행은 1,341건 중 1,336통과·3실패·2제외였으므로 전체 통과가 아니다. 격리 체크아웃의 줄바꿈 변환으로 발생한 기준 카탈로그 해시 실패는 파일 원본 복원 후 단일 테스트로 통과했다. 실수로 선택된 명시적 실제 Riot 네트워크 테스트는 401이었고, 가짜 전체 흐름의 `ImportFailed`는 원인 미확정이다. 실제 CommunityDragon 자료와 이미지 다운로드는 검증하지 않았다.
