# 경기 종료 조합 분석

조합은 경기 종료 시점에 기록된 기물 목록과 활성 시너지 종류로 구분합니다. 같은 기물이 여러 개라면 그 개수도 구분하지만 성급, 아이템, 증강, 시너지 활성 구간은 조합 구분에 넣지 않습니다. 이 목록은 마지막 전투에 실제 투입된 기물인지 별도로 증명하지 않습니다.

아이템이나 증강을 선택하면 조건에 맞는 참가자 기록만으로 통계를 다시 계산합니다. 기물과 아이템을 함께 선택하면 선택한 기물에 그 아이템이 장착된 기록을 사용합니다. 상대 조합 비교는 두 참가자 중 한쪽이 모든 조건을 만족하는 로비를 살펴보되, 조건을 적용하기 전 같은 조합이 여러 참가자에게 나타난 로비는 모호한 비교로 제외합니다.

필터를 바꾸는 동안 이전 결과와 CSV 저장은 잠시 비활성화됩니다. 최소 표본 기준과 증강에 대한 기존 표시 제한은 계속 적용됩니다. 경기 수집이 정상적으로 저장되어야 실제 결과를 볼 수 있으며, 서로 다른 지역·큐·티어 기록 라벨은 하나로 합산하지 않습니다.

갱신한 집계 캐시는 저장소의 `aggregates/3/generations/`에 보관합니다. 결과가 같으면 기존 캐시를 검증 후 재사용하고, 완성 캐시 또는 남겨진 임시 작업이 각각 32개에 도달하면 정리 안내를 표시합니다. 캐시를 직접 정리할 때는 분석 작업이 끝난 것을 확인하고 해당 폴더의 오래된 집계 캐시만 선택하세요. `observations/`의 익명 경기 기록과 카탈로그는 집계 캐시가 아닙니다. 저장소가 기본 위치인 경우 기준 경로는 `Library/TftAnalyzerStore/`입니다.
