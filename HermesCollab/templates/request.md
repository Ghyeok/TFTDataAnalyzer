## 목적과 요청 범위

수행할 작업과 범위를 작성한다. 실행 지시와 입력 자료는 모두 해당 작업 폴더에 둔다.

## 입력 자료

| 작업 폴더 기준 경로 | 원본 경로 | 설명 |
|---|---|---|
| `inputs/` 아래 실제 파일 경로 | 출처 정보만 기록 | 포함 범위와 기준 시점 |

## 확인 항목과 완료 조건

판단할 질문, 기대하는 결과, 필요한 검증과 출력 파일을 명시한다. 자료 준비가 끝났을 때 상태를 READY로 바꾼다.

## 허용 작업

기본값은 inputs의 읽기 전용 검토와 result.md·outputs 작성이다. 폴더 밖 자료가 필요하면 직접 읽지 말고 필요한 입력을 결과에 요청한다. 원본 파일 변경·Unity 상태 변경·Git 쓰기는 기본 허용 범위가 아니다.
