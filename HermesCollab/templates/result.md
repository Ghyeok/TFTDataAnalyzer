## 결과

요청의 각 완료 조건에 대한 결과를 작성한다. 아직 처리하지 않은 항목은 구분한다.

## 발견 사항

문제가 있으면 입력 파일의 위치, 근거, 재현 조건과 영향을 기록한다. 수정 제안·패치는 outputs에 저장하고 해당 경로를 적는다.

## 검증 증거

- 실행한 검증과 결과: 미실행
- 검증 출력 파일: 없음
- 미확인 사항:
- 소요 시간·확인 가능한 사용량·재작업 횟수:

## 필요한 후속 자료 또는 작업

추가 입력이 필요하면 BLOCKED와 필요한 자료를 명시한다. 산출물 저장을 모두 마친 뒤에만 상태를 COMPLETED 또는 BLOCKED로 바꾼다. COMPLETED는 응답 작성 완료이며 코드 승인이나 테스트 통과를 자동으로 뜻하지 않는다.
